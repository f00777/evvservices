1. Evv services necesita un ERP para administrar sus registros de clientes (cuentas, pagos, facturas, IVA)

2. Tambien necesitan registrar ordenes de compra, generación automática de ordenes de compra y facturas.

3. Esto permitirá ver a través la vista de historial todas las compras clientes y pagos realizados y recibidos.

4. De esta forma podrán tener control e información en tiempo real de cuanto adeudan sus clientes, tendrán centralizada la información para contactarlos y podrán ver las cuentas corrientes de estos.

5. VioERP, el ERP gestionado y desarrollado por 4Founders y el cual ya es utilizado por más empresas, es una solución integral que permite gestionar todas las operaciones de una empresa de manera eficiente, segura y fácil de aprender a utilziar

6. Se propondrá a EVV Services el uso de VioERP como solución para sus necesidades de gestión de clientes, compras y facturas. 

7. Además se propondrá un roadmap de desarrollo para agregar nuevas funcionalidades a VioERP según las necesidades de EVV Services, de tal forma que VioERP se convierta en una herramienta integral para la gestión de EVV Services. Siendo la cotización del desarrollo de nuevas funcionalidades para una próxima propuesta/cotización.

8. Se propondrá inicialmente a EVV Services un único usuario para su empresa, con los permisos necesarios para gestionar todas las operaciones de la empresa de tal forma que se les propondrá un precio de $100.000 + IVA mensual.y una prueba de 1 semana gratuita de tal forma que puedan testear si les conviene o no VioERP.
